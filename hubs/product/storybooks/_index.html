How nhetrinh
is built.

nhetrinh is a very small web browser for the Mac. These pages show how it is built. You will see the main parts, what each part does, and what runs while you browse.

The design in three lines.

nhetrinh draws the window, the tabs and the address bar.

Apple's WebKit does the hard work: it gets each page, runs it and draws it.

nhetrinh decides when a page may use memory. It gives the memory back when you do not use the tab.

nhetrinh is a thin layer between you and WebKit. nhetrinh's own code is about 7,900 lines of Swift. WebKit and macOS are already on every Mac.

These pages describe build d355a1e, the build you use now. Some work is still on other branches (for example, profiles). The pages mark that work where it appears.
