05 · PROCESSES

What runs
while you browse.

A process is one running program. A thread is one line of work inside a process.

nhetrinh is one process. WebKit starts its own helper processes next to it. nhetrinh controls the costly helpers: they exist only for tabs that are open.

3 · One thread does almost everything

Almost all of nhetrinh's own work runs on the main thread.

That sounds slow, but each job is tiny. The heavy work (pages, network, drawing) already runs in other processes.

One thread means two jobs never fight over the same data. The few side jobs give their answer back to the main thread before they change anything.

FASTYou click a tab. The main thread swaps one web view for another. No page is copied. WebKit keeps drawing.
IF SLOWA slow page freezes only its own page helper. The window, the tab list and the other tabs still answer.
