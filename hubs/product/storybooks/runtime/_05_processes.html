05 · PROCESSES

What runs
while you browse.

nhetrinh is one process. WebKit adds its own helper processes beside it, and nhetrinh decides how many of the costly ones exist by deciding which tabs are loaded.

3 · The one-thread rule

Almost everything nhetrinh does runs on the main thread. That sounds slow, but each piece is tiny: the heavy work (pages, network, drawing) is already in other processes. One thread means no locks and no races in the app's own state; the few background jobs hand their answer back to the main thread before touching anything.

FASTA click on a tab: the main thread swaps one web view for another. No page is copied; WebKit's processes keep drawing.
IF SLOWA slow page freezes only its own web content process. The window, the sidebar and the other tabs keep answering.
