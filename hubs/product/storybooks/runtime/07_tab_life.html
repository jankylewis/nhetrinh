07 · A TAB'S LIFE

Four states,
one costly.

A tab is cheap. It is an address, a title and an icon. Only an open tab holds a page in a WebKit helper. nhetrinh keeps tabs out of that state when you do not look at them.

1 · The four states

CLICK A STATE

NOT OPENED YETbrought back or opened behind · no web view · about 0 MB
▼you show it (click, ⌘1-9, ⌃⇥)
OPENweb view and its page helper · the costly state
▼unused 10 min · Put to Idle · memory low
▲you show it again
RESTINGdimmed in the tab list · back list kept · about 0 MB
▼you close it (from any state)
CLOSEDkept for ⌘⇧T, with its place in the groups

Read each arrow as a rule. A tab goes down to RESTING only when nhetrinh is sure you lose nothing. A tab goes up to OPEN only when you look at it.

2 · Tabs that never rest

SHOWNThe tab you see never rests. If you choose Put Tab to Idle on it, nhetrinh first shows the nearest other tab.
PLAYINGA tab that plays sound or video stays open. nhetrinh asks WebKit first.
IN A CALLA tab that uses the camera or the microphone stays open.
ALL OTHERSThey rest after the set minutes (10 by default). When memory is low, after 1 minute. When memory is very low, at once.
