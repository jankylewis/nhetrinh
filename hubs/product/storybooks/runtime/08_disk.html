08 · ON DISK

What is kept,
and where.

nhetrinh keeps four small files of its own, one Keychain item, and WebKit's store. It sends nothing to anyone: no account, no sync, no usage reports.

1 · The places

CLICK A BOX

~/Library/Application Support/nhetrinh/
session.jsonyour tabs and groups
prefs.jsonSettings Hub, zoom for each site
history.sqlitevisits, for the history list
running.markerwas the last quit clean?
KEYCHAINone item: kept sign-ins
WEBKIT'S STOREcookies · cache · site data
~/Downloadsyour downloads

Amber: nhetrinh writes these itself. Violet: macOS keeps it, locked. Green: WebKit looks after it. The checker uses its own profile, its own folder and its own store. It never touches these.

On a branch, not in your build yet: profiles (P10). They move these files into nhetrinh/Default/, one folder for each profile. Your files move once, at the first start.

2 · When nhetrinh starts

1 · WINDOWThe window and the menu appear first, empty.
2 · SIGN-INSIf the last quit was clean, nhetrinh reads the kept cookies from the Keychain. It puts them back into WebKit, and waits a moment so they arrive first.
3 · TABSnhetrinh reads session.json. Every tab comes back not opened yet. The tab you see loads. If the file is broken, nhetrinh keeps it aside as session.bad.json. It never deletes it.
4 · LINKSLinks that came in during the start open as new tabs. (For example, you clicked a link in another app.)

3 · When you quit

1 · TABSnhetrinh writes session.json at once.
2 · SIGN-INSnhetrinh asks WebKit for the sign-in cookies, and puts them in the Keychain item. It waits for that, then ends.
3 · CLEANnhetrinh removes the marker. Next time it starts, it knows this quit was clean.
