02 · COMPONENTS

The parts,
and what each does.

nhetrinh has seven main parts. The window controller is the centre. The views talk to it. It talks to WebKit. It follows rules that live in the core.

An arrow goes from the part that asks to the part that answers. The core never asks the app for anything. It only takes values and gives values back. So each rule can be tested in a few milliseconds.

3 · One more tool, outside the app

The readback is a separate checker program (nhetrinh-readback).

It starts the installed app, as you do. It uses the app step by step and checks what the app shows. Each step gets PASS or FAIL.

It talks to the app through a private line called the probe. The probe exists only when the checker starts the app. Your normal app has no probe.
