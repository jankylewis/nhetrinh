Where the code
lives.

The code is one Swift package. It has two programs, one shared library of rules, and three sets of tests. It uses only Apple's own frameworks (Apple's ready-made code). It uses no code from other companies.

One rule: the core may not use AppKit or WebKit. So every browser rule can be tested without a window. And no view can hide browser logic.

3 · Why the folders look like this

5 AT MOSTA folder holds at most 5 things. When it needs more, the code is grouped by meaning. That is why Page/Outside/ exists.
ONE _In each folder, exactly one name starts with _. It marks the most important thing. Open a folder and start there.
SMALL FILESA code file has at most 150 lines. A function has at most 30. A big part is split into files by topic, such as +Tabs, +WebKit and +Actions.
CHECKEDA checker script tests all of these rules before every commit. Nobody checks by eye.
