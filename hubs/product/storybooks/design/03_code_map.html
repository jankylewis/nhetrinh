3 · Why the folders look the way they do

≤ 5At most five entries in any folder. Past five, the code is grouped by meaning (that is why Page/Outside/ exists), never widened.
ONE _Exactly one entry per folder starts with _: the most important one. Open any folder and start there (_Browser/, _BrowserWindowController.swift).
SMALL FILESCode files at most 150 lines, functions at most 30. A big type is split into extensions by topic: BrowserWindowController+Tabs, +WebKit, +Actions.
BY TOOLA checker (scripts/conventions/_check.py) enforces all of this before every commit. Nobody checks by eye.
